# LaTeX

## What it is
LaTeX is a markup-based typesetting system used for technical and scientific documents.

## What I did
- Wrote `main.tex` with sections, a bulleted list, an equation and a table.
- Compiled it with `pdflatex` to get `main.pdf`.

## Key commands
| Command | Use |
|---------|-----|
| `\section{}` | Create a section |
| `\begin{equation}` | Numbered equation |
| `\label{}` / `\ref{}` | Cross-references |
| `\begin{tabular}` | Tables |
